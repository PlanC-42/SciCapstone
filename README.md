# Science Capstone Repository
Online repository for source code and animated figures for "Mapping Elemental Abundances in the Milky Way Across Galactic Time"
## Where to find files
Most image files are in relevent folders:

- All element maps are in "AllGalacticMaps"
- 3DMaps are in "3DMaps"
- "DraftNotebook" contains the code used during the whole exploration of the topic
- "FinalPlotsOnly" consists of a trimmed version that only contains final products
- "plotsAndLines.py" is a small library created for graphing and regressing data
